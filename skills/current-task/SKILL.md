# Текущая задача

Указатель — `.cursor/tasks/current`: одна строка, путь к папке задачи от корня workspace.

## Шаги при каждом вызове

1. Прочитать указатель. Файла нет или пользователь назвал другую папку → записать путь в указатель.
2. В папке задачи прочитать `INDEX.md`, `state.md` и последние записи `decisions.md`. Файлов нет → раздел «Первый запуск».
3. Пройти по текущему разговору с начала: подтверждённые решения, проверенные факты, изменения состояния. Чего нет в файлах — записать.
4. Ответить в 2–3 строках: что за задача, где стоим, следующий шаг, что дописано. Дальше работать по разделу «Записи».

## Файлы задачи

| Файл | Содержимое | Как меняется |
|---|---|---|
| `INDEX.md` | Задача в двух абзацах, таблица «вопрос → документ», ключевые файлы кода | Редко, при появлении новых документов |
| `state.md` | Сейчас / Сделано / Следующий шаг / Блокеры и открытые вопросы | Перезаписывается целиком |
| `decisions.md` | Дата, что решили, что это меняет. Без альтернатив | Только дописывается |
| `knowledge/*.md` | Документы знаний (код, конфиги, баги) — по ссылкам из `INDEX.md` | По мере исследования |

Новые файлы создавать только в `knowledge/`; корень папки задачи не пополнять.

## Записи

Писать сразу, в момент события, один короткий абзац:

- пользователь подтвердил предложение («ок», «делаем», «да, так») → `decisions.md`
- факт проверен по коду, базе или логам → документ в `knowledge/`, на который указывает `INDEX.md`
- сделан кусок работы, что-то застряло, сменился следующий шаг → `state.md`

Не писать: варианты, ход обсуждения, предложения без подтверждения пользователя.

## Первый запуск

Папка задачи есть, а `INDEX.md` / `state.md` / `decisions.md` нет:

1. Прочитать всё, что лежит в папке.
2. Если пользователь ещё не сказал, что за задача и чего хочет добиться — спросить.
3. Создать три файла: `INDEX.md` — из существующего README или оглавления папки; `state.md` — по словам пользователя; `decisions.md` — пустой, с заголовком.
4. Существующие документы не переписывать, только сослаться на них из `INDEX.md`.
